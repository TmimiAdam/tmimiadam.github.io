# Sources analysées pour la SAÉ3.ROM.04

Les quatre PDF fournis ont été lus avant modification du portfolio :

- `TP.pdf` : installation Asterisk, PJSIP, extensions, Fanvil, Cisco, TFTP, messagerie, IVR et trunk.
- `sécurisation.pdf` : transport TLS PJSIP, endpoints, identify, trunk et paramètres de sécurisation.
- `Mit.pdf` : notes d'analyse de vulnérabilités et d'écoute en environnement de TP contrôlé.
- `Soutenance Projet ToIP Asterisk.pptx.pdf` : synthèse finale du projet, architecture, services, trunk, Wireshark TLS et roadmap de sécurisation.

Les captures publiées dans le portfolio sont recadrées. Les mots de passe, adresses IP privées, adresses MAC et éléments offensifs détaillés ne sont pas publiés.
